# Oney3
Oneyplays randomizer PWA that handles file association with .csv filetype.
Doesn't seem to work on Android, but works ok on desktop Chromium or Chrome.
Once installed, open a .csv file from desktop and select the Oney3 app to open it.
See https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/How_to/Associate_files_with_your_PWA
See https://learn.microsoft.com/en-us/microsoft-edge/progressive-web-apps/how-to/handle-files
